Saved shipping address for agents. `agent credentials address` shows, saves, or clears the owner's shipping address, stored encrypted per wallet in Workers KV. Every owner sign-in links the install with an OMS-issued ID token, and `wallet link-credentials` links an already connected install. Dashboard links carry a signed one-hour token, and the new Credentials tab edits the address.
