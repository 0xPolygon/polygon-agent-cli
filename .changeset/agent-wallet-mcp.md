A remote MCP server for the agent wallet at `/mcp`, so agents that can't run the CLI can connect. The owner approves on a connect page with an email code or Google. Tools: `get_wallet` (address, holdings in dollars, dashboard link), `get_shipping_address`, `save_shipping_address`, `list_cards`, `add_card`, `check_card`, and `buy` (shop with the saved card; each purchase approved with the owner's passkey).
